## Informacije o analiziranom projektu  

Naziv projekta: Mafija  
GitLab repozitorijum: [https://gitlab.com/matf-bg-ac-rs/course-rs/projects-2025-2026/Mafija.git](https://gitlab.com/matf-bg-ac-rs/course-rs/projects-2025-2026/Mafija.git)  
Grana: `main`  
Heš kod komita: `31565d605391de059c56128639cb4a7ba7111ae2`  


Mafija je studentski projekat pisan u jeziku C++ u okviru kursa Razvoj softvera na Matematičkom fakultetu, Univerzitet u Beogradu. Mafija je igra za više igrača u kojoj je svakom igraču dodeljena uloga. Igrači na osnovu uloga imaju odgovarajuće moći koje mogu koristiti i koje im mogu pomoći prilikom glasanja za izbacivanje drugih igrača.
